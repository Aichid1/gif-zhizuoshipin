# gif制作视频

面向 Seedance 2.0 的产品视频提示词技能。上传一张产品场景图、一张白底产品图并指定横移方向后，技能会输出可直接复制的英文提示词，用单次直线运镜从延展场景进入目标构图。

## 使用方式

把整个 `gifzhizuoshipin` 文件夹放入 Codex 的 skills 目录：

```text
~/.codex/skills/gifzhizuoshipin/
```

然后调用：

```text
$gifzhizuoshipin
```

## 参考图分工

| 提示词名称 | 上传图片 | 职责 |
|---|---|---|
| Image 1 | 白底产品图 | 产品身份、包装轮廓、标签文字、图案与材质 |
| Image 2 | 产品场景图 | 最终构图、产品落点、环境、道具、光线与尾帧 |

技能默认输出 `1:1`、约 4–5 秒的单镜头产品视频提示词，并在镜头抵达场景图构图后保留约 1 秒稳定尾帧。

## 工作方式

1. 以白底图的包装和标签作为产品身份基准。
2. 以场景图作为机位终点，向镜头移动的相反方向延展连续环境。
3. 锁定包装正面朝向和标签可读性。
4. 用一次直线移动完成产品揭示，不在中途切镜。
5. 让终点的产品位置、比例、光线和道具关系对应场景图。
